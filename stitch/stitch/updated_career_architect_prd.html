# Updated Product Requirements Document: Ultimate CS Career Architect ## 1. Overview A dual-pillar AI platform for Indian CS students (IITs to private universities) focusing on: 1. **AI Resume Ecosystem:** Analyzer (3-Layer Audit) and Builder (Interview-based). 2. **Smart Project Suggester:** Suggesting high-LPA real-world projects with 2026 tech stacks. ## 2. Pillar 1: AI Resume Ecosystem ### Mode A: Analyzer * **3-Layer Audit:** * **ATS Check:** Compatibility with MNC/Startup portals. * **Specialization Alignment:** Keyword checks for AIML, Cyber, SDE, etc. * **Impact Scoring:** Improving bullet point quality. ### Mode B: Builder/Interview * **Conversational Data Gathering:** College, Spec, CGPA, Stack, Internships, Projects. * **Markdown Templates:** Role-specific (SDE, AI, DevOps, Data Analyst). ## 3. Pillar 2: Smart Project Suggester * **Function:** Suggests 3 unique projects for "50 LPA+ dreams" based on specialization. * **2026 Tech Stacks:** Agentic AI, RAG, Next.js 15, Rust, GoLang, Kubernetes. * **Output Structure:** Project Goal, MNC Demand, Unique Hook, Tech Stack, and the "LPA Tip" (Advanced Feature). ## 4. Visual Direction * **Theme:** Lumina Architect (Professional, Modern, High-Tech). * **Key Screens:** Landing Page, Interview, Analyzer, Project Suggester.
