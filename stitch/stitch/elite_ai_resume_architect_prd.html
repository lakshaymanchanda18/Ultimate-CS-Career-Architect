# Product Requirements Document: Elite AI Resume Architect & CS Career Coach ## 1. Overview An AI-powered platform tailored for Indian Computer Science students to build, audit, and optimize resumes for the modern tech landscape. The platform focuses on specialization-specific guidance (AI/ML, Cyber, SDE) and ATS compatibility for Indian MNCs and global startups. ## 2. Target Audience * **Students:** From Tier-1 (IITs/NITs) to Tier-3 (State/Private) universities. * **Degrees:** B.Tech, BE, BCA, MCA. * **Specializations:** Core CSE, AIML, Data Science, Cybersecurity, Cloud, IoT. ## 3. Core Features & User Flows ### Phase 1: The "Interview" (Onboarding) * Interactive, chat-like experience to collect data. * **Academic Stats:** College, Degree, Specialization, Batch, CGPA. * **Tech Stack:** Categorized (Languages, Frameworks, Tools). * **Experience:** Internships, Freelance, Open Source. * **Projects:** STAR/Google XYZ formula guided input. * **Extras:** Hackathons (SIH), Certifications, Leadership (GDSC/IEEE). ### Phase 2: The Analyzer (Resume Audit) * **Layer 1 (ATS):** Checks for structural issues (tables, columns) that break parsers. * **Layer 2 (Specialization):** Validates keywords against the student's field (e.g., Vector DBs for ML). * **Layer 3 (Content):** Upgrades weak bullet points to impact-driven statements. ### Phase 3: The Builder (Templates) * **Template A (SDE/Product):** Focus on DSA, LeetCode, Scalable Systems. * **Template B (Research/AI):** Focus on Math, ML Pipelines, Papers. * **Template C (Cyber/Ops):** Focus on Networking, Certs, Lab setups. ### Phase 4: The "Edge" (Optimization) * **Keyword Injector:** Role-specific hidden keywords. * **LinkedIn Optimizer:** AI-generated "About" and headlines. * **Portfolio Prompt:** GitHub pinning strategy. ## 4. Visual Direction * **Theme:** Professional, Modern, High-Tech, Trusted. * **Color Palette:** Deep Blues, Tech Purples, Clean Grays, Success Greens. * **Components:** Conversational UI, Progress trackers, Score cards, Template previews.
